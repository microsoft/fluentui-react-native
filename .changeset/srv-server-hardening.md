Harden the Desktop Driver server fences, capabilities and recovery. The named accessibility action route enforces the Storybook preview-context fence like click, clear and value, and story select and reset find the story root in any session window. Closing a session releases held input even when the settlement journal is down, leaves the application open if the release did not run, and lifts a launched application's quarantine only when a probe reports it exited. The journal adopts a record that storage created before failing, treats an absent record as removed, and bounds every storage and probe call. Unknown or mistyped `furn:` capabilities are rejected, and `furn:launchMode` is returned. Browser rejection also requires a loopback `Host` and no browser Fetch Metadata, the listener must bind a loopback address and keeps a permanent error handler. Startup options are validated strictly. A target registered after startup reads its journal before it is reported or opened. Timeouts are validated together, reject unsafe integers, accept a `null` script timeout, and an implicit wait ends when the session is deleted. Malformed percent-encoding is `invalid argument`, an unknown `/furn/*` route is `unknown command`, and `POST /window/new` is `unsupported operation`.
