Fix the agent operations. Observation paging and deltas no longer re-serialize the tree for every candidate, and a delta no longer issues references it does not return or for removed elements. `sequence` refuses a whole request up front for selector content the operator denies and for a strict-mode `clear` the target cannot perform. `act` names the proven reference and reports an unsupported `enabled` or `visible` state as `state-unsupported`, reports provider failures in fixed words, and reports a click that raised the window before failing as partial instead of rejected. `check` ends on an unsupported fact and spaces its evaluations. Malformed references and unknown fields no longer echo caller text, session capacities outside their ranges are rejected instead of clamped, and `complete` and `truncation` mean the same on `find`, `journal`, and `stories`. Document the missing failure reasons and `furn:inputMode`, and correct the `/agent` README row, which is not bounded.
