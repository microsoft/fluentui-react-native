# Avatar usage

Use Avatar to represent a person, group, bot, or other identifiable entity. Select an image when one is available, initials for a textual identity, or an icon for an entity without either. Give an informative standalone avatar an accessible name; leave it decorative when the same name is already visible next to it.

Use the supported numeric size that fits the surrounding density instead of scaling the component through custom styles. At size `16`, initials are intentionally reduced to one character. The activity ring is a visual cue only, so pair it with text if active status is meaningful.

Do not use Avatar as a button, status control, generic category icon, or an ad hoc overlapping avatar collection. Wrap it in a separate interactive component when activation is needed.
