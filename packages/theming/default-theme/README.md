# default-theme

The Fluent default themes for the fluentui-react-native components. `defaultFluentTheme` and `defaultFluentDarkTheme`
are the `@fluentui-react-native/design` package's `fluentLightTheme` and `fluentDarkTheme`, and `createDefaultTheme`
returns a `ThemeReference` that resolves the design package's `fluentTheme`, including its high-contrast themes, for the
requested appearance.
