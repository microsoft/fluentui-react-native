# Theming Utils

> **Deprecated:** Import the appearance helpers from
> `@fluentui-react-native/design/theming` instead. The token-pipeline mappers
> (`mapPipelineToTheme`, `mapFontPipelineToTheme`, and `mapPipelineToShadow`)
> are deprecated with no replacement; they remain available from
> `@fluentui-react-native/design/deprecated` for existing platform themes.

This package is a compatibility shim and will not receive new APIs. It preserves
the existing entry point while consumers migrate to the design package.
