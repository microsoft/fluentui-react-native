# Theme-tokens

> **Deprecated:** These Fluent 2 token values are deprecated and have no
> replacement API. They remain available from
> `@fluentui-react-native/design/deprecated` for existing platform themes; new
> code should use the generated Fluent themes from
> `@fluentui-react-native/design/themes`.

This package is a compatibility shim and will not receive new APIs. It preserves
the existing entry point while consumers migrate to the design package.
